Spain Map Web Component

Interactive map with smooth easing transitions and fast bounce animations

Features:

  • Three-level hierarchical navigation (CCAA → Provinces → Municipalities)
  • Smooth cubic-bezier easing with fast bounce (easeBackOut)
  • Hover tooltips with municipality information
  • Breadcrumb navigation + back button
  • Dynamic highlighting for "worked" municipalities
  • Responsive SVG layout

Implementation:

Built with Vue 3, D3.js, and TopoJSON. CSS transitions use cubic-bezier(0.34, 1.56, 0.64, 1) for smooth bounce effects. D3 transitions use easeBackOut for energetic fade animations.
